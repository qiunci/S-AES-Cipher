## 项目简介

S-AES（Simplified AES）是圣塔·克拉拉大学 Edward Schaefer 教授及其学生开发的教学用算法，
结构与 AES 相似但参数更少：**16 位分组、16 位密钥、2 轮**，运算在 GF(2⁴) 上进行。
它不是安全的加密算法，用来帮助理解 AES 的结构。

本项目依据《密码编码学与网络安全——原理与实践（第 8 版）》附录 D 实现，包含：

- **基本加解密**：16 位明文 + 16 位密钥 → 16 位密文，运算日志逐步展示每个变换的中间结果
- **ASCII 字符串加解密**：按 2 字节分组，密文以十六进制与“乱码”两种形式显示
- **多重加密**：双重（32 位密钥）、三重（32 位 K1+K2 或 48 位 K1+K2+K3）
- **中间相遇攻击**：已知明密文对，把 2³² 的密钥空间降到约 2×2¹⁶ 次运算
- **CBC 工作模式**：随机 IV、长明文加密、密文分组篡改后的解密对比

## 快速开始

### 环境要求

- JDK 17 或更高版本（开发与测试使用 JDK 21，代码用到了 `switch` 表达式和模式匹配 `instanceof`）
- 任意支持 Swing 的操作系统（Windows / macOS / Linux）
- 可选：Maven 3.8+（用于打包成可执行 jar）

### 编译与运行

```bash
# 1. 克隆仓库（把地址换成你自己的仓库）
git clone 【待补充：仓库地址】
cd S-AES-Cipher/S-AES

# 2. 编译
javac -encoding UTF-8 -d out src/main/java/saes/*.java

# 3. 运行图形界面
java -cp out saes.SAESGuiApp

# 4. 运行命令行自检（对照教材例子并输出测试数据）
java -cp out saes.SAESSelfTest
```

用 Maven 打包：

```bash
mvn clean package
java -jar target/saes.jar
```

### 基本加解密示例

| 项目   | 值                           |
| ------ | ---------------------------- |
| 密钥 K | `1010011100111011`（0xA73B） |
| 明文 P | `0110111101101011`（0x6F6B） |
| 密文 C | `0000011100111000`（0x0738） |

点击“加密”后，运算日志会显示完整过程：

```text
══════════ 16 位加密 ══════════
  输入                    : 明文 P = 0110 1111 0110 1011 (0x6F6B)，密钥 K = 1010 0111 0011 1011 (0xA73B)
  密钥扩展                : w0..w5 = A7 3B 1C 27 76 51
  轮密钥                  : K0 = ... (0xA73B)，K1 = ... (0x1C27)，K2 = ... (0x7651)
  第0轮 AK(K0)            : 1100 1000 0101 0000 (0xC850)
  第1轮 半字节代替 NS     : 1100 0110 0001 1001 (0xC619)
  第1轮 行移位 SR         : 1100 1001 0001 0110 (0xC916)
  第1轮 列混淆 MC         : 1110 1100 1010 0010 (0xECA2)
  第1轮 AK(K1)            : 1111 0000 1000 0101 (0xF085)
  第2轮 半字节代替 NS     : 0111 1001 0110 0001 (0x7961)
  第2轮 行移位 SR         : 0111 0001 0110 1001 (0x7169)
  第2轮 AK(K2)            : 0000 0111 0011 1000 (0x0738)
  输出                    : 密文 C = 0000 0111 0011 1000 (0x0738)
```

更详细的操作步骤见 [Using Instructions.md](Using%20Instructions.md)。

## 算法说明

```text
加密：AK(K2) ∘ SR ∘ NS ∘ AK(K1) ∘ MC ∘ SR ∘ NS ∘ AK(K0)
解密：AK(K0) ∘ INS ∘ ISR ∘ IMC ∘ AK(K1) ∘ INS ∘ ISR ∘ AK(K2)
```

| 单元          | 说明                                                                                                      |
| ------------- | --------------------------------------------------------------------------------------------------------- |
| 状态矩阵      | 16 位明文按列排入 2×2 半字节矩阵：前 8 位是第一列，后 8 位是第二列                                        |
| 半字节代替 NS | 查 S 盒（教材表 D.1），最左 2 位为行、最右 2 位为列                                                       |
| 行移位 SR     | 第二行循环移 1 个半字节；ISR 与 SR 相同                                                                   |
| 列混淆 MC     | 左乘 `[1 4; 4 1]`，在 GF(2⁴)（模 x⁴+x+1）上运算；IMC 左乘 `[9 2; 2 9]`                                    |
| 密钥加 AK     | 状态与 16 位轮密钥逐位异或                                                                                |
| 密钥扩展      | w2 = w0 ⊕ RCON(1) ⊕ SubNib(RotNib(w1))，w3 = w2 ⊕ w1，w4、w5 类推，RCON(1)=`10000000`，RCON(2)=`00110000` |

### 扩展部分的约定

| 功能              | 约定                                                                   |
| ----------------- | ---------------------------------------------------------------------- |
| ASCII 字符串      | 每 2 个字符为一组，高字节在前；字符数为奇数时末尾补 `0x00`，解密后去掉 |
| 双重加密          | `C = E(K2, E(K1, P))`，32 位密钥 = K1（高 16 位）+ K2（低 16 位）      |
| 三重加密（32 位） | `C = E(K1, D(K2, E(K1, P)))`                                           |
| 三重加密（48 位） | `C = E(K3, D(K2, E(K1, P)))`，密钥 = K1 + K2 + K3                      |
| CBC               | `C_i = E(K, P_i ⊕ C_{i-1})`，`C_0 = IV`（16 位）                       |

> 做交叉测试时，请和对方确认这些约定（尤其是补位规则和多重加密的密钥顺序）是否一致。

## 接口文档

核心类 `SAESCore` / `MultiSAES` / `CBCMode` 不依赖任何界面代码，可直接在其他程序里调用：

```java
int c = SAESCore.encryptBlock(0x6F6B, 0xA73B);          // 0x0738
int p = SAESCore.decryptBlock(c, 0xA73B);               // 0x6F6B
String bits = SAESCore.encrypt("0110111101101011", "1010011100111011");

long key32 = 0xA73B2D55L;
int c2 = MultiSAES.doubleEncrypt(0x6F6B, key32);

int[] cipherBlocks = CBCMode.encryptText("Hello, CBC!", 0xA73B, CBCMode.generateIv());
```

完整接口说明见 [Development Manual.md](Development%20Manual.md)。
